《小满·见微》V26｜你拼好的长卷 · 前景动画测试

一、启动
解压整个压缩包，进入 xiaoman_site，双击 start_windows.bat，浏览器打开 http://127.0.0.1:8026/ 。
不需要安装 Python。关闭服务器用 Ctrl+C。

二、替换高清背景（无需更改代码）
将你的高清 PNG 改名为 landscape_user.png，然后替换 assets 文件夹中的同名图片。
请保持整幅图像内容和长宽比例一致；其他前景层按长卷的相对横坐标定位。
提示：当前用户预览图只有1536×144，放大至桌面全屏会模糊，替换高清版即可改善。

三、操作
A/D 或左右方向键漫步；按住 Shift 快行；空格跳跃；E 观察；鼠标点击按钮可自动漫游、调整音乐。
探索页为2D小满，最后收藏页保留带底座3D小满。3D模型需要联网加载Three.js。V26修正版已添加Import Map，明确映射 three 与 three/addons，避免GLTFLoader内部的 bare specifier 报错；如果网络无法访问 jsDelivr，3D结束页仍无法加载，但2D游览不受影响。

四、美术设置
没有重新生成或重新拼接背景。新增的是低密度前景素材，经过少量透明裁切，以轻柔的摆动模拟风、草、麦浪。
本包里的前景素材是候选版本，若觉得边缘、透视或数量不合适，可继续删减。

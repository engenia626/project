《小满·见微》V28 更新说明

基础版本：V27 tuned（保留 V26/V27 原有长卷、2D人物逐帧行走、三项观察任务、音效、自动结束页和原有布局）。

本次新增：
1. 大型前景花树：左侧大树、中央冠形大树、右上横向花枝。
2. 垂柳大型摆件：荷塘岸边垂柳、上方横向垂柳枝、侧向柳枝。
3. 横向接缝遮挡：苔石花草、石块草带、花灌木、麦穗草带。
4. 动态氛围素材：风线、细雨、远景雨幕、水纹、落叶、花瓣、溅水、薄雾（已纳入资源目录，尚未全部挂载为交互动画）。

场景装饰按长卷世界坐标稀疏放置，前后景分层：
- layer-behind：在小满后方，增强空间纵深；
- layer-front：在小满前方，形成局部遮挡。
未更换人物设定、人物序列、背景长卷或任务逻辑。

运行：
Windows 双击 start_windows.bat
浏览器访问 http://127.0.0.1:8020/
如需结束服务，在终端 Ctrl+C。


V28.1 修订：
- 提高前景层关键遮挡素材不透明度（前景草丛、石块、花枝、麦穗等），后景保持较轻透明度。
- 新增 sfx_water_step.wav：荷塘/水岸行走使用柔和水花声，不再误播金属感石板脚步声。
- 石桥仍使用较轻的石板脚步声；水面环境声继续作为连续底噪。

- V28.1：新增三处实际挂载的横向接缝遮挡（苔石花草、花灌木、麦穗草带），并提高关键前景层不透明度。
- 荷塘/水岸行走改用柔和水花脚步声；石桥才使用轻石板脚步声，避免水边触发金属感石板声。

Resource library: assets/resource_library_batches contains the available previous batch archives (02–09) for reference and future selection. Batch 01 was not present in the working directory and is therefore not represented here.


V28.2 音效修订：
- 完全移除石板脚步声与荷塘/水岸脚步声，不再播放任何行走触发音效。
- 保留背景音乐、连续水环境声与亭子提示音。
- 本次仅处理声音，不改变小满的行走路径；人物经过水面区域的路线定位仍需单独调整。
